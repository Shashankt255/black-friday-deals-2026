# Contributing to Black Friday Deals 2026

Thanks for helping keep this list the best Black Friday resource on GitHub!

## Adding a Deal

### Option 1: Pull Request (preferred)

1. Fork this repo
2. Edit `README.md` — add your deal to the correct category table
3. Use this format:

```
| [Product Name](https://official-deal-url.com/) | Short description | **XX% OFF** — code `COUPON` (dates) | ✅ |
```

4. Submit a PR with a clear title: `Add: ProductName BF2026 deal`

### Option 2: Open an Issue

Not comfortable with PRs? [Open an issue](https://github.com/Shashankt255/black-friday-deals-2026/issues/new) with:
- Product name and URL
- Deal details (discount, coupon code, dates)
- Status (confirmed or expected)

## Updating a Deal

- Deal expired? Change ✅ to ❌ or remove the row
- Price changed? Update the deal column
- Deal confirmed? Change ⏳ to ✅

## Rules

- **No affiliate links** — use the vendor's direct URL only
- **No fake deals** — regular pricing marketed as a discount will be rejected
- **Verified only** — include a source if the deal isn't on the vendor's homepage
- **One deal per row** — don't combine multiple products
- **Keep it concise** — one-line descriptions only

## Categories

Add deals to the most relevant existing category. If no category fits, suggest a new one in your PR description.

## Review

PRs are reviewed within 24 hours during November. Straightforward additions (correct format, real deal, right category) are merged quickly.
